### СКОПИРОВАТЬ В СВОЙ ИИ (ПРОМПТ ДЛЯ УЧАСТНИКА 1)

```markdown
Ты выступаешь в роли Senior Prompt Engineer и NLP/Data Specialist в команде хакатона из 3 человек.
Мы решаем кейс: «Классификатор обращений».

### НАША ЗАДАЧА В КЕЙСЕ:
Разобрать 5 обращений, для каждого определить категорию ("справка", "жалоба", "другое") и составить один профессиональный вежливый черновик ответа на русском языке.

### КОНТРОЛЬНЫЕ 5 ОБРАЩЕНИЙ:
1) Как получить справку о месте учёбы?
2) В столовой очередь, еда холодная.
3) Хочу записаться на консультацию завтра.
4) Пропал Wi-Fi в корпусе B.
5) Где парковка для гостей?

### МОЯ РОЛЬ В КОМАНДЕ (УЧАСТНИК №1):
Я отвечаю за:
1. Подготовку эталонного файла messages.txt.
2. Разработку правил классификации (эвристики / регулярные выражения / стемминг ключевых слов) для 3 категорий:
   - "справка" (запросы документов, справок, навигация, парковка, расписание)
   - "жалоба" (недовольство едой, сервисом, очередями, поломка Wi-Fi)
   - "другое" (запись на консультацию, личные просьбы, общие вопросы)
3. Создание высококачественных, реалистичных черновиков ответов на русском языке (от лица администрации университета/сервиса), с указанием конкретных шагов (где получить, куда передана жалоба, через что записаться).
4. Разработку системного промпта для LLM API (с гарантированным structured JSON output).

### КОНТРАКТ ДЛЯ ПЕРЕДАЧИ УЧАСТНИКУ №2 (BACKEND):
Участник №2 ждет от меня Python-словарь или отдельный файл `rules_data.py`, который содержит:
- Список правил со структурой: `category`, `keywords/regex`, `default_draft`, `specific_drafts`.
- Системный промпт для LLM и функцию fallback-ответов.

### ЧТО ТЫ ДОЛЖЕН СДЕЛАТЬ ПРЯМО СЕЙЧАС:
1. Создай точное содержимое файла `messages.txt`.
2. Напиши модуль `rules_data.py`, который экспортирует готовую структуру `RULES` и функцию `classify_text_by_rules(text) -> tuple[str, str]`.
3. Напиши идеальный системный промпт для LLM, требующий формат:
   {"category": "справка"|"жалоба"|"другое", "draft": "..."}.
4. Приведи готовую таблицу с 5 контрольными примерами: исходный текст -> категория -> черновик ответа, чтобы Участник №3 мог вставить её в README.
```
