# Классификатор обращений (Кейс №01)

Компактный и надежный CLI-инструмент для автоматической первичной классификации входящих обращений по трем категориям (`справка`, `жалоба`, `другое`) и генерации качественных черновиков ответов для службы поддержки. Решение разработано в рамках тренировочного дня хакатона.

---

## 🚀 Как запустить

> **Требования:** Python 3.8+. Сторонние библиотеки не требуются (**Zero External Dependencies**).

### 1. Быстрый запуск (базовый режим правил, оффлайн)
```bash
python classifier.py
```
*По умолчанию считывает обращения из `messages.txt` в корне проекта.*

### 2. Вывод в формате JSON (для пайплайнов и интеграций)
```bash
python classifier.py --json
```

### 3. Свой файл с обращениями
```bash
python classifier.py -f path/to/my_messages.txt
```

### 4. Запуск с использованием LLM API (опционально)
Поддерживается OpenAI и любые совместимые шлюзы (ProxyAPI, OpenRouter, vLLM):
```bash
# Windows (PowerShell):
$env:OPENAI_API_KEY="sk-..."; python classifier.py --mode llm

# Linux / macOS:
OPENAI_API_KEY="sk-..." python classifier.py --mode llm
```
*Если ключ не задан, превышена квота или отсутствует сеть — скрипт выдаст предупреждение в `stderr` и автоматически выполнит надежную классификацию по правилам (**Graceful Fallback**).*

### 5. Запуск автоматических тестов (QA)
```bash
python test_classifier.py
```

## 💡 Архитектурные особенности решения

- ⚡ **Zero-dependency:** мгновенный запуск «из коробки» без `pip install` на чистом Python 3.
- 🛡️ **Graceful Fallback:** защита от сбоев внешних API — при недоступности LLM результат всегда гарантирован правилами.
- 🪟 **Кроссплатформенность UTF-8:** встроенная переконфигурация потоков вывода для Windows (PowerShell/CMD), Linux и macOS.
- 🔄 **Чистый stdout:** при флаге `--json` в стандартный вывод поступает только валидный JSON; логи и предупреждения изолированы в `stderr`.
- 🧹 **Устойчивый парсинг:** автоматическое очищение ведущих номеров вида `1)`, `2.`, `[3]`, пропуск пустых строк и корректная обработка UTF-8 с BOM.
