# Классификатор обращений (Кейс 01)

Легковесный скрипт для автоматической первичной сортировки входящих обращений и генерации черновиков ответов для службы поддержки. Разработано в рамках тренировочного дня хакатона.

---

## 🚀 Как запустить

Скрипт написан на **Python 3** с использованием исключительно стандартной библиотеки — установка сторонних пакетов не требуется!

### 1. Быстрый запуск (режим правил / эвристик, оффлайн)
```bash
python classifier.py
```
По умолчанию скрипт считывает обращения из файла `messages.txt`.

### 2. Запуск с выводом в формате JSON
```bash
python classifier.py --json
```

### 3. Запуск через LLM API (опционально)
При наличии ключа OpenAI (или совместимого шлюза):
```bash
# Windows (PowerShell):
$env:OPENAI_API_KEY="ваш_ключ"; python classifier.py --mode llm

# Linux / macOS:
OPENAI_API_KEY="ваш_ключ" python classifier.py --mode llm
```
*Примечание: Если ключ не задан, скрипт автоматически переключится на надежный rule-based режим.*

### Особенности решения
- ⚡ **Zero-dependency:** мгновенный запуск на любой машине без `pip install`.
- 🛡️ **Отказоустойчивость:** гибридная архитектура (Rule-based + LLM fallback).
- 🗂️ **Корректный парсинг:** автоматическое очищение нумерации в исходных строках.
