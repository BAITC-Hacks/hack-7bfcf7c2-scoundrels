### НАША ЗАДАЧА В КЕЙСЕ:
Написать маленький, надежный скрипт `classifier.py`, который считывает 5 сообщений из `messages.txt`, классифицирует их по трем категориям ("справка", "жалоба", "другое") и печатает для каждого категорию и один черновик ответа на русском языке.

### МОЯ РОЛЬ В КОМАНДЕ (УЧАСТНИК №2):
Я отвечаю за:
1. Архитектуру и реализацию основного исполняемого скрипта `classifier.py`.
2. Чтение и парсинг файла с обращениями (с очисткой от префиксов вроде "1) ", "2. ", пустых строк).
3. CLI-интерфейс через `argparse`:
   - `-f`, `--file` (путь к файлу сообщений, дефолт: `messages.txt`);
   - `--mode` (выбор режима: `rules` или `llm`, дефолт: `rules`);
   - `--api-key` (ключ для LLM или чтение переменной окружения `OPENAI_API_KEY`);
   - `--json` (вывод чистого массива JSON для интеграций).
4. Подключение логики правил (от Участника №1) и логики вызова LLM API.
5. Отказоустойчивость: если флаг `--mode llm` указан, но ключа нет, нет интернета или API вернул ошибку — скрипт НЕ ДОЛЖЕН падать! Он обязан выдать предупреждение в stderr и автоматически выполнить классификацию через rules (Graceful Fallback).
6. Кроссплатформенность: чистая стандартная библиотека Python 3 (без сторонних pip-пакетов, чтобы скрипт запускался моментально у любого проверяющего), поддержка UTF-8 в Windows-консоли (`sys.stdout.reconfigure`).
